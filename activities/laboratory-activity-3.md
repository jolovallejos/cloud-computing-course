# Laboratory Activity 3: Mission 3 – Multi-Cloud Explorer

## AWS Exploration

### KillerCoda Laboratory

**Laboratory:** Laboratorio AWS I

### AWS Services Explored

| Service | Category | Purpose |
|---|---|---|
| Amazon EC2 | Compute | Provides virtual servers or instances for running applications. |
| Amazon S3 | Storage | Provides object storage for files and data. |

### AWS Laboratory Results

The AWS laboratory demonstrated the use of Amazon EC2 and Amazon S3. The laboratory involved configuring AWS, creating/reviewing an EC2 instance, and creating an S3 bucket.

### Observation

AWS provides different cloud services for different infrastructure needs. EC2 is useful for computing resources, while S3 is useful for storing data.
