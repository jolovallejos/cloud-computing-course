# Cloud Platform Recommendations for Client Scenarios

## Client A – Startup Company

### Recommended Platform: **Google Cloud Platform (GCP)**

### Why:
GCP is ideal for startups with limited budgets. It offers $300 in free credits, simple pricing, and excellent mobile development tools like Firebase. The platform scales efficiently as the business grows.

### Services to Use:
1. Google Compute Engine
2. Firebase
3. Cloud Firestore
4. Cloud CDN

---

## Client B – University

### Recommended Platform: **Microsoft Azure**

### Why:
The university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides seamless integration with these existing systems, making migration easy and cost-effective.

### Services to Use:
1. Azure Virtual Machines
2. Azure Active Directory
3. Azure SQL Database
4. Azure Virtual Desktop

---

## Client C – AI Research Company

### Recommended Platform: **Google Cloud Platform (GCP)**

### Why:
GCP is the best choice for AI research with specialized TPU hardware, Vertex AI platform, and BigQuery for large datasets. It offers end-to-end machine learning lifecycle management.

### Services to Use:
1. Google Cloud TPUs
2. Vertex AI
3. BigQuery
4. AI Platform

---

## Client D – Global E-Commerce Company

### Recommended Platform: **Amazon Web Services (AWS)**

### Why:
AWS has the most global regions for serving customers worldwide. Its Auto Scaling, load balancing, and CloudFront services deliver high availability and performance for global retail operations.

### Services to Use:
1. Amazon EC2 Auto Scaling
2. Amazon CloudFront
3. Amazon RDS
4. AWS WAF & Shield

---

## Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---------------------|---------------------|---------------|
| Startup Company | GCP | Cost-effective, generous free tier |
| Microsoft Environment | Azure | Native integration with Microsoft |
| AI / Machine Learning | GCP | Best AI/ML tools and TPUs |
| Global Web Application | AWS | Most global regions and mature services |
| Kubernetes Deployment | GCP | Originated Kubernetes, best GKE |
| Enterprise Organization | AWS | Largest ecosystem and service breadth |
