## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the most services with over 200 offerings. It has the largest ecosystem and most mature platform.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Windows Server, Active Directory, Office 365, and Dynamics 365.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) excels in both AI/ML and Kubernetes. It developed TensorFlow and originated Kubernetes.
