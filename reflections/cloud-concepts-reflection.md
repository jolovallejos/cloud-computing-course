# Reflection: Cloud Computing Concepts

Cloud computing is already a part of my everyday life because I regularly use different applications that depend on internet-based services. Three cloud services that I frequently use are Google Drive, Canva, and Messenger.

Google Drive is a Software as a Service (SaaS) because it allows me to create, store, and access files without managing the servers or infrastructure behind the service. I classify it as a Public Cloud because it is available to many users through the internet. Canva is also SaaS because it provides online graphic design tools that I can use without installing or maintaining the underlying system. It can also be considered a Public Cloud service because it is accessible to users through the internet. Messenger is another example of SaaS because it provides communication features through an application while the service provider manages the servers and infrastructure. It can also be classified as a Public Cloud service because it is available to many users.

These services show how cloud computing makes technology more convenient and accessible. I can access my files, create designs, and communicate with other people using different devices as long as I have an internet connection.

Git and GitHub are also important when developing cloud-based projects. Version control allows developers to record changes, compare different versions of files, and restore previous versions when necessary. This is important because cloud projects may involve many files and multiple developers working at the same time. GitHub provides a central platform where team members can collaborate, review changes, and manage project versions. Features such as commits, branches, and pull requests help reduce mistakes and prevent unwanted changes from affecting the main project.

Overall, cloud computing provides convenient access to applications and resources, while Git and GitHub help developers organize, track, and collaborate on projects effectively.
