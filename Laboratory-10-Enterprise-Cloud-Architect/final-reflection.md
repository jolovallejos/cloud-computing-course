# Final Reflection: Mission 1 to Mission 10

Looking back at my journey in Cloud Computing, I started as a beginner who barely knew how to navigate a Linux terminal. Through the missions, I learned how to manage cloud infrastructure step-by-step.

For this final mission, I acted as the Enterprise Cloud Architect. I built a complete multi-tier application from scratch using VirtualBox and Ubuntu Server. The most challenging part was configuring the network (Host-Only Adapter) and setting up the Docker containers. However, troubleshooting these issues taught me how to be resilient and resourceful.

I successfully deployed a WordPress and MySQL stack, secured it using UFW, and automated backups using Bash and Cron. I realized that being a Cloud Architect is not just about deploying servers, but ensuring they are secure, persistent, and self-healing.

This project gave me the confidence to design and manage my own infrastructure. I learned that documentation and disaster recovery are just as important as the deployment itself. I am proud to finish this course not just as a student, but as an aspiring Cloud Professional.
